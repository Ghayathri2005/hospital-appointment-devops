# Hospital Appointment Booking System - Phase 1

A simple Flask + SQLite web application for the DevOps Integrated Mini Project.

## Features
- Hospital home page
- Doctor listing
- Appointment booking
- Appointment listing
- Appointment cancellation
- SQLite database

## Run locally

### 1. Create virtual environment
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Start application
```bash
python app.py
```

### 4. Open in browser
http://127.0.0.1:5000

The database `hospital.db` is automatically created when the application starts.
